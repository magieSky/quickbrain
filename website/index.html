    下载 速脑 Setup 1.0.0.exe，双击安装。Windows 10 / 11 (x64)，约 110 MB。

    安装后右下角托盘出现图标。试试 Alt + K 唤出搜索，Ctrl + Alt + N 快速记录。

    打开 ⚙️ AI 设置，填一个 API Key（DeepSeek / Kimi / GLM / 通义千问 / Ollama 任选），即可启用 AI 格式化与语义搜索。

技术亮点

为「数据自主」而设计

01

本地优先

笔记默认存在本地 SQLite。零账号、零云上传、零追踪，开箱即用。

02

多 LLM 灵活切换

不绑定单一厂商。OpenAI 兼容接口均可接入，可选本地 Ollama 让 AI 也不出本机。

03

SaaS + 自托管

开箱即用 SaaS（note.bjhzsk.cn）；有数据顾虑可一键部署自托管服务端，HMAC 鉴权 + 账号隔离，笔记权限由你掌控。

04

原生应用体验

基于 Electron + Native Messaging；全局快捷键不抢系统焦点冲突，托盘常驻、随开随用。

安装步骤

  1. 01

    下载并解压

    下载 quickbrain-extension-v0.3.0.zip 后解压到任意文件夹（路径不含中文更稳妥）。

  2. 02

    打开扩展页

    Chrome 地址栏输入 chrome://extensions/ 并回车。

  3. 03

    开启开发者模式

    点击页面右上角的「开发者模式」开关（Developer mode）。

  4. 04

    加载已解压的扩展

    点击「加载已解压的扩展程序」按钮（Load unpacked），选择刚才解压的文件夹。

  5. 05

    配置后端地址

    点击工具栏扩展图标（拼图块 → 闪电图标）→ ⚙️ 设置：
    · 本地：Endpoint URL 留默认 http://127.0.0.1:7421，Auth Token 留空（需要桌面端已启动）；
    · SaaS 云端：Endpoint URL 填 https://note.bjhzsk.cn，先在桌面端「设置 → 同步」注册账号并把 Auth Token 复制过来。

  6. 06

    开始使用

    在任意网页选中文字 → 右键「保存选中到速脑」；或直接右键页面「保存整页到速脑」。笔记会出现在桌面端主面板。

小提示

  • 扩展默认每次保存都会生成新的 deviceId（UUID），与服务端 HMAC 鉴权一一对应。
  • 想在多台电脑共用同一账号？把同一台机器的 Auth Token 复制到另一台即可。
  • Edge / Brave 等 Chromium 内核浏览器操作一致；Firefox 需要单独打包（暂未提供）。
  • 若右键菜单没出现，请确认扩展已启用、且已「固定到工具栏」。
