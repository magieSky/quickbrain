核心特性

不只是笔记，更是你工作流的 第二大脑

从一条 URL 到一整篇文档，从碎片想法到结构化知识 — 速脑 都能用最短路径进入、用最快方式检索。

⚡

全局快捷键唤起

按 Alt + K 在任何应用中唤出搜索面板，输入关键字即可秒搜。

📥

一键记录

按 Ctrl + Alt + N 唤出输入面板，文字、代码、链接 — 写完即存。

🔍

毫秒级多模搜索

全文 + 拼音 + 语义三路召回，本地 SQLite 即时响应，无需联网、无需账号。

✨

AI 一键格式化

把零散文字整理成结构化 Markdown，让 AI 帮你归类、打标、提炼要点。

🌐

网页一键采集

Chrome 扩展：右键「整页入库」或选中文字「保存到速脑」，原文 + URL 一并存。

☁️

可选多端同步

本地默认；需要时自托管服务端（Fastify + Postgres），HMAC 鉴权、数据自主可控。

上手指南

3 步开始用 速脑

  1. 01

    下载安装

    下载 QuickBrain Setup 1.0.0.exe，双击安装。Windows 10 / 11 (x64)，约 90 MB。

  2. 02

    唤起面板

    安装后右下角托盘出现图标。试试 Alt + K 唤出搜索，Ctrl + Alt + N 快速记录。

  3. 03

    配置 AI（可选）

    打开 ⚙️ AI 设置，填一个 API Key（DeepSeek / Kimi / GLM / 通义千问 / Ollama 任选），即可启用 AI 格式化与语义搜索。

技术亮点

为「数据自主」而设计

01

本地优先

笔记默认存在本地 SQLite。零账号、零云上传、零追踪，开箱即用。

02

多 LLM 灵活切换

不绑定单一厂商。OpenAI 兼容接口均可接入，可选本地 Ollama 让 AI 也不出本机。

03

自托管同步

服务端 50 MB 镜像一键起，HMAC 鉴权，端到端加密通道（设计中），数据完全可控。

04

原生应用体验

基于 Electron + Native Messaging，无浏览器开销；快捷键不抢系统焦点冲突。
